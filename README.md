AccuKnox Omni (marketed as AccuKnox VM Scanner) is an agentless,
multi-platform VM scanner. It supports GCP, AWS, Azure, and OpenShift, with
Nutanix and OCI support coming soon. It also provides an agent-based
installation method for platforms not currently supported. Once installed,
Omni scans your VMs for vulnerabilities and malware. Support for EOL
software/OS scanning and compliance benchmarks (STIG, CIS) is planned.
